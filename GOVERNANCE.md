# Governance

Savorum has one maintainer, who decides what merges and what the product does.

## Roles

| Role        | Who                                       | Responsibilities                                                                                      |
| ----------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Maintainer  | Jonathan la Cour ([@laCour][maintainer])  | Reviews and merges changes, publishes releases, answers security reports, administers the repository. |
| Contributor | Anyone who opens an issue or pull request | Submits changes under the terms in [`CONTRIBUTING.md`](CONTRIBUTING.md).                              |

Only the maintainer has write or administrative access to this repository and
to the `savorum` GitHub organization that hosts it.

## Decisions

Feature proposals are judged against the
[product principles](docs/contribute/product-principles.md). Existing
maintainers add new maintainers.

[maintainer]: https://github.com/laCour
